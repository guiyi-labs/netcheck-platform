# 用户操作手册

> 按角色讲解平台各页面功能与完整巡检操作流程。

## 1. 登录与角色

- 登录地址：`http://localhost:8080/login.html`
- 默认管理员：**admin / admin123**
- 登录失败 5 次将锁定 15 分钟。
- token 有效期默认 24 小时，过期后需重新登录。

| 角色 | 权限 |
|---|---|
| admin | 全部功能 + 用户管理 |
| operator | 全部业务操作（增删改资产/任务/告警处置） |
| viewer | 只读（访问写接口返回 403） |

## 3. 典型巡检流程

### 3.1 准备资产

资产管理 → 新建资产（名称、IP、主机名、端口、检测类型）或「批量导入」CSV：

```csv
名称,IP,主机名,端口
demo-web-ok,10.0.0.1,,443
```

- 必填：名称、IP；重复 IP 自动跳过。
- 检测类型可选 ping/port/http/dns/tls，勾选决定该项资产跑哪些检查。

### 3.2 创建巡检任务

巡检任务 → 新建任务：

- **名称**：如「生产环境每日巡检」
- **检测类型**：勾选需要执行的全集（Ping/端口/HTTP/TLS）
- **资产**：选择纳入本次巡检的资产
- **调度**：可选 Cron 表达式（如 `0 9 * * *` 每天 9 点），留空则仅手动触发

### 3.3 触发与观察

- 手动「运行」：立即创建一次运行，进入队列。
- 「任务运行详情」实时显示 pending → running → completed/failed/cancelled（WebSocket 推送，断线自动回退轮询）。
- 运行中可「取消」；失败/取消可「重试」。

### 3.4 查看结果与处置

- 结果页按状态筛选（成功/警告/失败），点「详情」看目标、耗时、消息/错误。
- 诊断页展示 fault_type（如 ping_unreachable）与建议；admin/operator 可触发 **AI 增强建议**（需配置 AI）。
- 告警中心对达到策略等级的告警进行确认/恢复处置。

### 3.5 报告

报告管理 → 生成报告（选择时间范围与任务）→ 下载（PDF/CSV）→ 本地归档。

## 4. 高级操作

| 功能 | 入口 | 说明 |
|---|---|---|
| 资产导入导出 | assets.html | 导出带 BOM 的 CSV，Excel 可直接打开 |
| 网络诊断 | diag.html | 输入 IP/域名跑 traceroute，看逐跳 RTT 与中断点 |
| 趋势分析 | trends.html | 选资产 + 天数（1-90），看延迟/可用率/耗时 |
| Grafana 大屏 | http://localhost:3000 | 资产/任务/告警/耗时指标总览（自动供给） |
| 审计追踪 | audit.html | 按用户/动作/对象/时间筛选所有写操作 |

## 5. 演示数据

首次启动自动写入 12 条演示资产（seed），含正常/故障/慢响应三类站点（demo-web-ok / demo-web-error / demo-web-slow），便于立即演练告警与诊断链路。
