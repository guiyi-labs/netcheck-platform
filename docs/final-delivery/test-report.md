## 3. 异常测试表

| 编号 | 场景 | 预期结果 |
|---|---|---|
| E01 | 未登录访问业务接口 | 返回 401 |
| E02 | 停用任务后执行 | 返回错误提示 |
| E03 | HTTP 500 服务 | 巡检结果 failed，诊断为 Web 应用内部错误 |
| E04 | 慢响应服务 | 巡检结果 warning，诊断为性能下降 |
| E05 | 非法 CIDR 资产发现 | 返回错误，不执行扫描 |
| E06 | 超过 256 个扫描目标 | 返回错误，保护网络边界 |
| E07 | 重复导入已有 IP | 不重复创建资产 |
| E08 | 下载不存在的报告 | 返回 404 |
