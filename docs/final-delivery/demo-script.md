# 答辩演示脚本

> 建议时长：5-8 分钟
> 演示环境：Docker Compose 本地演示环境

## 演示前准备

```powershell
docker compose up -d --build
```

打开：

```text
http://localhost:8080/login.html
```

登录账号：

```text
admin / admin123
```

## 演示流程

### 1. 登录与仪表盘

页面：`http://localhost:8080/index.html`

讲解点：

- 系统面向中小型网络自动化巡检和故障诊断。
- 首页展示资产状态、巡检趋势、故障类型分布、告警统计和最近异常。
- 平台已形成巡检、诊断、告警、报告闭环。

### 2. 资产台账

页面：`http://localhost:8080/assets.html`

讲解点：

- 统一管理网络资产。
- 演示资产包括正常 Web、异常 Web、慢响应 Web 服务。
- 支持资产新增、编辑、删除、状态展示。

### 3. 巡检任务

页面：`http://localhost:8080/tasks.html`

建议操作：

- 创建或查看巡检任务。
- 选择资产：`demo-web-ok`、`demo-web-error`、`demo-web-slow`。
- 检测类型选择：Ping、端口、HTTP、DNS。
- 展示定时巡检配置。

讲解点：

- 支持多资产、多检测类型。
- 支持手动执行和定时执行。
- DNS 检测补齐网络检测维度。

### 4. 执行巡检并查看运行详情

页面：`http://localhost:8080/task-run.html`

建议操作：

- 点击任务的“立即执行”。
- 进入运行详情。

预期结果：

- `demo-web-ok`：正常。
- `demo-web-error`：HTTP 500 失败。
- `demo-web-slow`：慢响应 warning。
- DNS 检测可解析 Docker 服务名。

### 5. 巡检结果查询

页面：`http://localhost:8080/results.html`

讲解点：

- 支持全局结果查询。
- 可按运行 ID、任务 ID、资产、检测类型、状态、时间筛选。
- 所有巡检结果均可追溯。

### 6. 故障诊断

页面：`http://localhost:8080/diagnosis.html`

讲解点：

- 系统自动根据结果生成诊断。
- HTTP 500 对应 Web 应用内部错误。
- 慢响应对应网络拥塞或服务性能下降。
- 每条诊断包含等级、依据和处理建议。

### 7. 告警中心

页面：`http://localhost:8080/alerts.html`

讲解点：

- 告警从诊断结果中升级而来。
- 支持连续失败阈值、恢复阈值和去重。
- 支持确认和手动恢复。

演示建议：

- 默认策略为连续失败 3 次、连续恢复 2 次。
- 如需快速演示，可临时改为 1/1，演示后恢复默认值。

### 8. 报告管理

页面：`http://localhost:8080/reports.html`

建议操作：

- 输入运行 ID 生成报告。
- 下载 Excel。

讲解点：

- 报告包含巡检概况、异常资产、故障类型、处理建议。
- 可作为运维留痕和论文测试材料。

### 9. 资产发现

页面：`http://localhost:8080/discovery.html`

建议输入：

```text
127.0.0.1
```

端口：

```text
8000,8080
```

讲解点：

- 仅扫描授权小范围。
- 支持发现在线主机和开放端口。
- 发现结果可导入资产台账。

### 10. 逻辑拓扑

页面：`http://localhost:8080/topology.html`

讲解点：

- 拓扑展示核心网络和资产节点。
- 节点颜色体现资产状态。
- 该拓扑为逻辑拓扑，不是 SNMP/LLDP 自动物理拓扑。

## 收尾说明

系统已形成完整闭环：

```text
资产台账 -> 巡检任务 -> 检测执行 -> 结果留痕 -> 故障诊断 -> 告警闭环 -> 仪表盘展示 -> 报告导出 -> 资产发现与拓扑展示
```
